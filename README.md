One sentence, one roast: the lawmaker writing the rules for artificial intelligence still prints every email, signs it in pen, scans it back in, and calls the result a PDF. `main.py` writes that single sentence to `/output/entry.txt` — 147 characters, one sentence, deterministic on every run.

## Run it

```sh
python3 main.py
```

Locally, the output goes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write elsewhere, e.g. `MAKEFUN_OUTPUT_DIR=out python3 main.py`.
